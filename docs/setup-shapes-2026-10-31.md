# Setup symbols and semantic colors

Alma requested shapes for model/setup distinctions after removing categorical colors.

Color has one role throughout the atlas: green marks algorithm guarantees and red marks lower bounds. A setup uses the same shape in both colors. Neutral paint remains on axes, panel boundaries and text. Hollow markers retain their explicitly documented limit, conditional, historical or symbolic meaning.

The shared `AtlasSymbols` primitive supplies circle, square, triangle, diamond, hexagon, plus and downward triangle outlines. Shapes have local meanings stated in each figure's legend; they do not declare different graph classes or objectives comparable. Overview and enlarged renderings retain the same setup identity.

Examples include one/two streaming passes, adaptive/non-adaptive LCA probes, list-query graph and error contracts, dynamic output/query contracts, coloring palettes/adversaries, and independent-set graph families. Correlation clustering retains its shared approximation scale and separate objectives. MIS LCA's algorithm ranges are green again; categorical accents do not determine bound paint.

The figure-first layout excludes decorative legend SVGs when selecting the live chart host. Sources, publication filters, keyboard interaction, and open-problem sections are retained. No theorem values or literature coverage changed in this release.

Validation: complete renderer regression suite; 61 routes using the shared primitive with 1,434 semantic marks checked at three zoom sizes; all 68 figure routes inspected through browser navigation; desktop and mobile, dark and light; overview computed-color audit and source-inspection checks. Each live deployment and offline artifact is recorded separately in the workspace release evidence.
