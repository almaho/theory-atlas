# Online column removed

Alma requested removal of the Online column on 2 November 2026. Its catalog entry now has `visible: false`, using the same existing visibility mechanism as Combined / other queries. Research records and renderers remain archived.

The public atlas has eight columns and 56 cells. The setting picker contains 61 figure routes; Online is absent from grid cells, picker entries and search destinations. All 12 archived Online route identifiers, in both legacy `#focus-` and `#atlas/` forms, return to the overview. Visible coverage is 266 papers and 472 scoped results.

The full renderer suite passes. Navigation checks cover both hidden models, their preserved research and old links. Shape checks cover all 54 visible routes using the shared marker primitive, the seven reviewed native-symbol routes, and archived Online shapes through their own renderer. All 435 visible figure source markers resolve.

Browser inspection covered the desktop overview, setting picker, an old Online link, search, an enlarged matching LCA figure and a 390px mobile overview. The remaining columns retain their order, with Stochastic last. No document overflow was observed.
